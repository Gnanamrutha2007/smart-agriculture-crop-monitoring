About the System

The Smart Agriculture Crop Monitoring System helps farmers monitor crop conditions and manage farm activities through a cloud-based platform.

The system will use AWS IoT Core, Lambda, DynamoDB, S3, CloudWatch and SNS along with authentication and API services.
